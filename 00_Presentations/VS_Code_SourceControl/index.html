VS Code Source Control
02 · Concept

Source Control이란?

VS Code 안에서 Git을 사용할 수 있도록 제공되는 GUI와 편의 시스템입니다.
  • 파일의 변경사항 확인
  • 변경사항 Stage
  • Commit 생성

핵심 장점

Git의 상태와 변경 내용을 화면에서 직접 확인하면서 작업할 수 있습니다.

Source Control = Git 작업을 GUI로 관리

10 · Terminal

알아두면 좋은 Git 명령어

git clone  원격 Repository 복제
git init    현재 폴더를 Repository로 초기화
git add    변경사항 Stage
git commit  변경사항을 로컬 기록으로 저장
git push    로컬 Commit을 원격으로 업로드
git pull     원격 변경사항을 내려받아 반영

GUI의 기능과 터미널 명령어를 연결해서 이해하면 Git의 동작 방식을 파악하기 용이합니다.

GUI ↔ Git Command
